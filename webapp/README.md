## About

**GitRecap Web** is the Next.js frontend for GitRecap, a Spotify Wrapped-style GitHub analytics app. Built with **Next.js**, **TypeScript**, and **Tailwind CSS**, it renders GitHub user profiles with interactive charts, contribution heatmaps, language breakdowns, and a developer personality summary — all visualized using **Chart.js** and react-calendar-heatmap.

## Features

- GitHub username input with OAuth callback handling
- Contribution heatmap calendar built with react-calendar-heatmap
- Bar and pie charts for weekly commit patterns and language usage via Chart.js
- Developer personality type derived from coding behavior
- Stats display including repos, stars, followers, longest streak, and favorite language
- Commit time distribution and top repositories breakdown
- Vercel Analytics integration for usage tracking

## Technology Stack

- **Frontend**: Next.js, React, TypeScript, Tailwind CSS
- **Charts**: Chart.js, react-chartjs-2, react-calendar-heatmap
